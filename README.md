# Avatar Variant Selector

単体のアバターで複数のBlueprint IDを切り替えられるようにし、複数のアバターとして管理するためのツールです。  
例えば、同じ改変で日焼けしていない物と日焼けしている物など、「ほとんど同じだけど少しだけ違うアバター」を作ると複製を別々に管理することになり、複数に同様の改変を加えたい時に手間が発生します。  
このツールのコンポーネントに差分を作る小さな操作を登録し、それぞれに個別のBlueprint IDを記憶させ、それをアバターバリアントとして切り替えることでその手間を解消します。

## おおまかな流れ

シーンには常に「全部入り」の構成を置いておきます。  
例えば、ヘッドホンをつけたアバターとカチューシャをつけたアバターで別々のバリアントを構成したいのであれば、両方のアクセサリを付けておいてください。  
NDMFのビルドが行われる際、各バリアントに登録された操作が行われます。

最初にバリアントを作成した時、 `Pipeline Manager` に既存のBlueprint IDが記載されている場合、最初のバリアントに転記されます。  
バリアントを切り替えた際、バリアントに登録されたBlueprint IDが `Pipeline Manager` に書き込まれ、アップロード先になります。  
登録されたBlueprint IDが空の時は新規アップロードアバターとしてアップロードされ、生成されたBlueprint IDがコンポーネントに保存されます。  
以降、そのバリアントを選択した時はそこにアップロードされるようになります。

バリアントがひとつもなく、 `Pipeline Manager` に既存のBlueprint IDが記載されている場合、ビルドが中断します。  
通常通りアップロードしたい場合、コンポーネントを削除してください。

同じ Blueprint ID を複数のバリアントに入れた場合、警告が出ます。ビルドはリストで先に見つかったバリアントで通ってしまうため、警告は放置せず直してください。

## 使い方

1. アバタールート( `VRC Avatar Descriptor` と同階層)に `Avatar Variant Selector` コンポーネントを追加します
2. 「プロファイルを作成」を押して `Avatar Variant Profile` アセットを作ります
   - `Assets/MinMinMart/AvatarVariantSelector/Profiles/` に、アバター名を付けて作られます
3. バリアントを追加し、名前と Blueprint ID を入力します
4. 各バリアントに、ビルド時の操作を登録します
   - **削除するオブジェクト** — そのバリアントのビルドから取り除く
   - **マテリアルを差し替える** — Renderer のマテリアルスロットを上書きする
   - **ブレンドシェイプを変える** — SkinnedMeshRenderer のシェイプ値を設定する
   - よく似たバリアントは「複製」で増やせます。操作内容は引き継ぎ、Blueprint ID だけ空になります
5. 「アップロード先を切り替え」でバリアントを選び、通常どおりアップロードします

### 新しいアバターとしてアップロードする

Blueprint ID が空のバリアントは「新規アップロード対象にする」で選べます。  
アップロード後、生成された Blueprint ID は自動でそのバリアントに保存されます。

### シーンやアバターを複製したとき

設定はプロファイルアセットにあるため、シーンやアバターを複製すると、複製先も複製元と同じプロファイルを参照したままになります。気付かずにそのまま新規アップロードすると、採番された Blueprint ID が複製元のバリアントにも書き込まれてしまいます。

そこでプロファイルには持ち主のセレクターが記録してあり、食い違いを見つけると Inspector に警告が出ます。

- **複製して差し替える** — プロファイルを分けます。バリアントの内容はそのまま引き継ぐので、要らない Blueprint ID だけ消してください
- **このセレクターを持ち主にする** — 複製ではなかった場合（シーンを別名で保存して移動しただけ、など）はこちらを選びます

アップロード直後の書き戻しだけは確認を待てないため、持ち主が食い違っていると自動でプロファイルを複製し、そちらへ書き込みます。複製元は変更されません。この場合は Inspector にその旨が表示されます。

プロファイル欄の右にある「新規」「複製」からも、いつでも分けられます。


## 必要環境

- Unity 2022.3
- VRChat SDK - Avatars 3.7.0 以上
- NDMF 1.13.1 以上

Modular Avatar には依存しません。

## 言語

Inspector は日本語と英語に対応しています。表示言語は Inspector 上部のポップアップで切り替えられます。
