# Avatar Variant Selector

1 つのシーンから、複数のアップロード先ぶんのアバターをビルドするツールです。

NSFW 版と全年齢版のように「ほとんど同じだけど一部だけ違う」アバターを別々のシーンで管理していると、片方に加えた改変がもう片方に反映されず、いつの間にか内容がずれていきます。このツールはシーンを 1 つに保ったまま、ビルド時に差分を作ることでその問題を解消します。

## 仕組み

シーンには常に「全部入り」の構成を置いておきます。各バリアントは NDMF のビルド中に**引き算**して作られるため、バリアントを切り替えてもシーンは変更されません。

どのバリアントをビルドするかは、アバタールートの `PipelineManager` が持つ **Blueprint ID** との一致で決まります。アップロード先とビルドされる内容が同じ 1 つの値から決まるので、**「NSFW 構成を全年齢アバターにアップロードしてしまう」事故が構造的に起きません。**

Blueprint ID がどのバリアントにも一致しない場合、ビルドは**中断**されます。推測はしませんし、中断を回避する設定もありません。

## 使い方

1. アバタールートに `Avatar Variant Selector` コンポーネントを追加します
2. 「設定アセットを作成」を押して `Avatar Variant Set` アセットを作ります
   - `Assets/MinMinMart/AvatarVariantSelector/Profiles/` に、アバター名を付けて作られます
3. バリアントを追加し、名前と Blueprint ID を入力します
4. 各バリアントに、ビルド時の操作を登録します
   - **削除するオブジェクト** — そのバリアントのビルドから取り除く
   - **マテリアルを差し替える** — Renderer のマテリアルスロットを上書きする
   - **ブレンドシェイプを変える** — SkinnedMeshRenderer のシェイプ値を設定する
5. 「アップロード先を切り替え」でバリアントを選び、通常どおりビルド＆アップロードします

### 新しいアバターとしてアップロードする

Blueprint ID が空のバリアントは「新規アップロード対象にする」で選べます。アップロード後、**採番された Blueprint ID は自動でそのバリアントに書き写され、その場で保存されます。**

## 設定がアセットにある理由

設定の実体は `AvatarVariantSet` アセットに置いています。アップロードで採番された Blueprint ID をスクリプトから保存できるようにするためで、シーンを保存し忘れても設定を失いません。

編集した内容がアセットへ書き出されるのは、操作を登録したとき、名前や数値の入力欄からフォーカスが外れたとき、ビルド時、シーンを保存したときです。1 文字打つたびに書き出すと再インポートが走って重くなるので、区切りの良いところにまとめています。「適用」のような確定操作は要りません。

その代わりアセットからシーン内オブジェクトを参照できないため、対象は**アバタールートからの相対パス**で保持します。Inspector では従来どおりオブジェクト参照欄で選べます（内部でパスに変換）。リネームや移動でパスが切れた場合は Inspector に警告が出て、ビルドは中断されます。

## 他のツールとの実行順

NDMF の `FirstChance` フェーズで、他のどのプラグインよりも先に実行されます。「そもそもどのアバターをビルドするか」を決める処理だからです。

これは実用上も必要でした。VRCQuestTools の Platform GameObject Remover は `Resolving` フェーズでオブジェクトを削除するため、後から走るとこちらの削除対象が「パス切れ」に見えてしまいます。`FirstChance` に置くことで、Resolving 以降で削除を行うあらゆるツールに対して先行できます。

副次的に、NDMF の EditorOnly 除去よりも前に走るため、**EditorOnly なオブジェクトも削除対象に登録できます。**

## 必要環境

- Unity 2022.3
- VRChat SDK - Avatars 3.7.0 以上
- NDMF 1.13.1 以上

Modular Avatar には依存しません。

## 言語

Inspector は日本語と英語に対応しています。表示言語は Inspector 上部のポップアップで切り替えられ、選択は `EditorPrefs` に保存されます。初期値はエディタのシステム言語から判定します。

辞書は `Editor/AvatarVariantSelector/Localize/ja.json` および `en.json` です。
